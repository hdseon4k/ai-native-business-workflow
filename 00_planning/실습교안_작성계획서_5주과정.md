## 1. 기존 2시간 특강안(`학위과정특강.md`) 재검토 및 확장 설계 방향

### 1.1 기존 2시간 특강안의 한계점 (Gap Analysis)
1. **실습 깊이의 제약**: 120분 단일 세션 특성상 로컬 컨테이너 스택 구동부터 Sub-workflow 도구 바인딩까지 수강생이 직접 구현하기 어려워 **강사 주도 시연(Live Demo)**에 의존할 수밖에 없었음.
2. **사내 지식 베이스(RAG) 생략**: 엔터프라이즈 에이전트의 핵심인 비정형 문서(사내 규정, 장애 매뉴얼) 임베딩 및 Vector DB 결합 과정이 시간 관계상 제외됨.
3. **프로덕션 예외 처리 미흡**: sLM 특유의 JSON 스키마 파싱 실패, 무한 루프, API 타임아웃 복구 및 **Human-in-the-Loop(인간 승인 개입)**를 개념적으로만 언급하고 실제 노드 구현이 누락됨.

### 1.2 15시간(3시간 × 5주) 확장 시 핵심 설계 원칙
- **단일 캡스톤 누적 빌드업 (Progressive Build-up)**: 매주 단절된 예제를 실습하는 대신, **"망분리 엔터프라이즈 지능형 ITSM(IT 서비스 관리) & 비즈니스 운영 자동화 플랫폼"**이라는 하나의 시스템을 1주차(인프라/정형화) $\rightarrow$ 2주차(RAG 지식화) $\rightarrow$ 3주차(멀티 툴 에이전트) $\rightarrow$ 4주차(장애 복구/인간 승인) $\rightarrow$ 5주차(하이브리드 통합/평가)로 점진적 고도화.
- **회차별 3시간(180분) 표준 모듈화**:
  - **1교시 (50분)**: 전공 CS/AI 핵심 이론 및 아키텍처 패턴 해설 (Why & How)
  - **휴식 (10분)**
  - **2교시 (55분)**: 기초 핸즈온 실습 **Lab A** — 핵심 노드 구성 및 단일 파이프라인 검증
  - **휴식 (10분)**
  - **3교시 (55분)**: 심화 핸즈온 실습 **Lab B** — 비즈니스 예외 처리, 서브 워크플로우 결합 및 체크포인트 검증

  1. **1교시 (50m) | CS/AI 아키텍처 이론**:
     - 결정론적 체인(Deterministic Chain) vs 자율 에이전트(Autonomous Agent, 유한 상태 기계 FSM 관점)
     - LLM Tool Calling(Function Calling) 내부 메커니즘: 도구 명세 JSON 주입 $\rightarrow$ 모델의 `tool_calls` 토큰 생성 $\rightarrow$ 오케스트레이터 실행 $\rightarrow$ Observation 재주입 루프

     - 실행 로그(Execution Trace)를 통해 에이전트의 단계별 추론(Thought)과 도구 호출 파라미터 검증

     - 에이전트에 3종의 이기종 도구를 동시 장착하여 복합 의사결정 수행:

       - **Tool 3 (`Vector Store Tool`)**: Week 2에서 구축한 사내 SLA 및 장애 복구 매뉴얼 검색

  - sLM이 도구 호출 인자를 누락하지 않게 유도하는 Few-shot System Prompt 템플릿

### 📅 Week 4: 프로덕션 신뢰성 엔지니어링 — 결함 내성 및 Human-in-the-Loop (3H)

- **학습 목표**: 에이전트의 오작동(파싱 에러, 무한 루프, 할루시네이션)을 방어하는 가드레일 패턴을 구현하고, 고위험 비즈니스 액션 실행 전 인간의 승인을 거치는 비동기 Human-in-the-Loop(HITL) 워크플로우를 구축한다.
- **시간 배분 및 교안 세부 목차**:
  1. **1교시 (50m) | CS/AI 아키텍처 이론**:
     - 엔터프라이즈 AI 도입의 최대 걸림돌: 비결정성(Non-determinism)과 실행 리스크
     - 분산 워크플로우의 결함 내성(Fault Tolerance): Retry, Fallback Model, Circuit Breaker, 멱등성(Idempotency)
     - 비동기 Human-in-the-Loop 아키텍처: 상태 직렬화(State Serialization)와 Resume Webhook 메커니즘
  2. **2교시 (55m) | Lab 4-A: 출력 파싱 복구 및 에러 핸들링 파이프라인**:
     - `Auto-fixing Output Parser`를 통한 깨진 JSON 응답 자동 교정
     - 노드 레벨 `Retry On Fail` 및 에러 출력 분기(Error Output Branch) 설정
     - `Error Trigger` 전용 워크플로우를 구축하여 워크플로우 실패 시 실패 노드, 입력 페이로드, 타임스탬프를 감사 DB 및 관리자 채널에 자동 기록
  3. **3교시 (55m) | Lab 4-B: Human-in-the-Loop(HITL) 승인 게이트웨이 구현**:
     - **시나리오**: Week 3 에이전트가 장애를 분석한 결과 **"VIP 고객사 DB 커넥션 풀 초기화 스크립트 실행 및 보상 크레딧 발행"**이라는 고위험 액션을 제안 $\rightarrow$ 즉시 실행하지 않고 온콜 엔지니어에게 승인/반려 링크가 포함된 알림 발송 $\rightarrow$ n8n `Wait` 노드(Wait for Webhook Call)로 상태 동결 $\rightarrow$ 엔지니어의 `[승인]` 클릭 시 자동 조치 실행 및 `[반려]` 시 수동 티켓으로 우회.
- **교안 필수 포함 산출물**:
  - 프롬프트 인젝션(Prompt Injection) 및 권한 남용 공격 예제와 입력 검증(Input Guardrail) 노드 구성법
  - `Wait` 노드 Resume URL(`{{ $execution.resumeUrl }}`) 보안 서명 및 타임아웃 처리 설계도

- **학습 목표**: n8n(엔터프라이즈 시스템 통합 백본)과 외부 전문 AI 프레임워크(LangGraph/FastAPI)를 결합하는 하이브리드 패턴을 실습하고, 5주간 구축한 모듈을 통합하여 프로덕션급 비즈니스 에이전트 캡스톤을 완성·평가한다.

     - 프레임워크 적재적소 배치 전략: **n8n (I/O & Workflow Backbone)** + **Dify / LangGraph (Deep Reasoning & Multi-Agent Core)** 하이브리드 아키텍처
