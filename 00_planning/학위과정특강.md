# 특강 기획안: 망분리 엔터프라이즈를 위한 AI Native 비즈니스 워크플로우

> **부제**: n8n과 온프레미스 sLM(Ollama)으로 구축하는 실무 에이전틱 오케스트레이션  
> **대상**: 컴퓨터공학·소프트웨어·산업공학·경영정보 학위과정 학부 3~4학년 및 대학원생  
> **소요 시간**: 총 120분 (50분 이론/아키텍처 + 10분 휴식 + 60분 라이브 핸즈온/엔지니어링)

---

## 1. 강의 개요 및 목표

### 1.1 기획 의도
단순한 SaaS 챗봇(ChatGPT API) 연동 수준을 넘어, 데이터 보안 및 망분리를 요구하는 실제 엔터프라이즈 환경에서 **온프레미스 sLM과 비즈니스 시스템(DB, API, 메신저)을 결합한 에이전틱 파이프라인**의 설계 및 구현 역량을 체득한다.

### 1.2 학습 목표
1. **패러다임 이해**: 규칙 기반 전통적 RPA와 자율형 AI Native 워크플로우의 아키텍처적 차이를 규명할 수 있다.
2. **에이전트 메커니즘 습득**: sLM(Qwen 2.5/Llama 3.1)의 Tool Calling 원리와 ReAct 루프 동작 방식을 이해한다.
3. **실무 파이프라인 구축**: n8n 캔버스에서 Webhook, 로컬 LLM, 커스텀 Sub-workflow Tool을 유기적으로 연결하여 장애 대응 자동화 에이전트를 구현할 수 있다.
4. **프로덕션 고려사항 인지**: 환각 방어, 상태 관리, Human-in-the-Loop(인간 개입 승인), Sustainable Use 라이선스 정책을 파악한다.

## 3. 실습 시나리오 아키텍처 (Part 3)

```
[1. 고객 문의 인입]
    Webhook 노드 (POST /ticket/inquiry)
    페이로드: {"customer": "A사", "query": "어제 배포 이후 DB 커넥션 풀 에러가 발생하며 서버가 다운됩니다."}
         │
         ▼
[2. n8n AI Agent 노드 (Core Orchestrator)]
    Model: Ollama (Qwen 2.5 7B-Instruct)
    System Prompt: "당신은 IT 장애 분석 엔지니어입니다. 주어진 도구를 활용해 고객 등급과 과거 이력을 조회한 후 긴급도를 판별하세요."
         │
    ├───▶ [Tool 1: 사내 DB 조회 (n8n Sub-workflow)]
    │       Postgres Mock DB에서 고객 계약 등급(VIP 여부) 및 최근 3개월 장애 로그 조회
    │
    └───▶ [Tool 2: 인프라 상태 모니터링 (HTTP Request)]
            실시간 서버 메트릭 API 호출
         │
         ▼
[3. 최종 액션 및 분기 실행]
    - 긴급(Critical) 판정 시: 긴급 Slack 채널 알림 + 온콜 엔지니어 멘션
    - 일반 판정 시: Jira 백로그 티켓 자동 발행 및 고객 회신 초안 생성
```

## 4. 대학 학위과정 맞춤형 운영 가이드

1. **CS 핵심 이론과의 매핑**:
   - 단순 툴 사용법 교육을 지양하고, **이벤트 주도 아키텍처(Event-Driven Architecture), 유한 상태 기계(FSM), REST API 설계, 모델 양자화(Quantization: GGUF/AWQ)** 등 전공 필수 이론과 실습 노드를 직접 연결하여 설명.
2. **실습 환경 편차 방어**:
   - 수강생 PC 사양 편차 및 로컬 다운로드 병목을 방지하기 위해 강사 주도 라이브 코딩을 중심으로 진행하며, 실습 완료 후 즉시 복습할 수 있는 **Docker Compose 올인원 템플릿(n8n + Ollama + Mock DB)** 배포.
3. **진로 및 연구 연계**:
   - 최근 산업계에서 수요가 급증하는 **AI Systems Architect, LLMOps Engineer, Agentic Workflow Specialist** 직무 로드맵 제시 및 대학원 연구(Multi-agent, HITL) 주제 가이드 제공.
